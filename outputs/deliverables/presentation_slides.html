Problem

Problem Statement

Can a locally-hosted fine-tuned LLM give reproducible, evidence-grounded
BIST equity analysis — without inventing numbers or giving investment advice?

Two Hard Constraints

🔢 Never invent numbers — every numeric claim must come from a tool output

⚠️ No investment advice — only 8 educational labels allowed

Why Local?

✓ Fully verifiable — offline, no cloud dependency

✓ Reproducible — same model, seed 17, temperature 0, same answers

✓ Student-controlled — no API keys, no costs

Limitations

Honest Limitations

1. A 3B Model Reads, It Does Not Reason

Correct answers depend on the tools doing the comparisons. In one dry run on an 8-sector output, the label was right but the explanation quoted another sector's figures.

2. Grounding ≠ Attribution

The audit proves each figure exists in a tool output; it cannot prove the figure is attached to the right ticker. Sector answers need a human read.

3. Over-Cautious Outside Its 5 Question Types

On the 20-question eval: 11 answers say ANALYSIS_UNSAFE, only 2 should. It doesn't know tools it wasn't trained on (asked for project_status, it ran the quality gate).

4. Works Only in Its Own Tool Format

Trained without tool schemas; given Ollama's 21 schemas it chains extra tools (invalid calls 0.45 vs 0.05 for the base). The presentation path uses the training format.

5. Fundamentals for THYAO Only

Other tickers return available: false and get INVESTIGATE. Pre/post-TMS 29 statements are never mixed (PERIOD_MISMATCH hard-block).

6. Evaluator and Safety Limits

Only 4 of 20 eval questions expect a particular label. No RLHF: "no advice" rests on the prompt, the 8 labels and the quality gate.
